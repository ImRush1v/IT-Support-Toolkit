# IT Support Toolkit

A Python-based command-line diagnostic toolkit designed to perform common IT support and troubleshooting checks from a single menu.

## Features

- System information
- Network information
- Internet connectivity testing
- Disk usage monitoring
- DNS resolution testing
- Interactive command-line menu

## Technologies Used

- Python
- Git
- Windows command-line utilities
- Python standard library

## Current Diagnostic Tools

### 1. System Information
Displays useful system information including:
- Computer name
- Operating system
- OS version and release
- System architecture
- Processor information

### 2. Network Information
Displays:
- Hostname
- Local IP address

### 3. Internet Connection Test
Tests internet connectivity by sending a ping request to an external IP address.

### 4. Disk Usage
Displays:
- Total disk space
- Used disk space
- Free disk space
- Disk usage percentage

### 5. DNS Test
Tests whether a domain name can successfully resolve to an IP address.

## How to Run

Make sure Python is installed.

Clone or download the repository, open a terminal inside the project folder, and run:

```bash
python it_support_toolkit.py
